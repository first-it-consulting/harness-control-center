# ADR-0014: MCP: agents use servers through their proxy; the Control Center is a read-only server

- Status: accepted
- Date: 2026-10-26

## Context

MCP lets agents use tools other people wrote, and lets the user's own
assistant read the state of their systems. Both directions are channels
for actions and for prompt injection, so they need the same treatment as
everything else: granted explicitly, enforced outside the agent, gated
where they act.

## Decision

- **Agents use what `spec.mcp.servers` names**, either:
  - a remote server (`url`, https): an ordinary egress destination,
    reached through the egress proxy and so the allowlist (its host must
    be in it) and the credential broker; or
  - an installed `mcp-server` plugin (`plugin`): a stdio MCP server run
    for each job in a sandbox of its own (ADR-0013), started on first use
    and stopped with the job. The agent reaches it only at
    `/hcc/v1/mcp/<name>` on its own proxy; the runner relays JSON-RPC
    between them (`hcc-guest plugin-shim` carries the server's stdin and
    stdout inside its VM). A runner rejects a harness naming a plugin it
    does not have.
  The claude-code image configures Claude Code with exactly these
  servers (`--strict-mcp-config`).
- **Tool calls can be gated.** `approvals.requireFor` accepts
  `mcp.<server>.<tool>` (tool names in lower case), `mcp.<server>.*` and
  `mcp.*`, for declared servers only. For plugin servers the runner holds
  the call; for remote ones the proxy (inspecting, as for any gate) reads
  every POST to the server's endpoint: a body it cannot read in full, or
  whose arguments cannot be shown in full (over 2 KiB), is refused. The
  person sees the server, the tool and its complete arguments. Denied
  calls get a JSON-RPC error and never reach the server.
- **The Control Center is a read-only MCP server**: `hcc control mcp`
  speaks MCP over stdio, for an assistant the user runs; nothing listens.
  Its tools list runners, jobs (with the end of a console), schedules,
  pending approvals and saved harnesses, and explain a harness. None
  starts, stops or approves anything; a person does that. Agent-written
  text in its answers is neutralized and declared untrusted.

## Consequences

- Plugin MCP servers cost a plugin slot for as long as their job runs.
- Server-to-client requests (sampling, elicitation) are not relayed for
  plugin servers.
- Text from agents reaches the user's assistant through the read-only
  server; it can mislead that assistant, but not act through it.
